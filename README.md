# WanderLust-Complete-end-to-end-Full-Stack-Web-Application-
Developed a full-stack web application using MVC architecture with Node.js, Express.js, MongoDB, and EJS. Implemented authentication, CRUD operations, RESTful routing, session management, reviews, and responsive UI using Bootstrap and MongoDB Atlas.
# WanderLust

WanderLust is a full-stack Airbnb-inspired web application built using Node.js, Express.js, MongoDB, and EJS. Users can create, edit, explore, and review travel property listings with secure authentication and session management.

## Features

* User Authentication & Authorization
* Create, Edit, Delete Listings
* Add & Manage Reviews
* RESTful Routing
* MVC Architecture
* Session Management using MongoDB
* Flash Messages & Form Validation
* Responsive UI using Bootstrap
* MongoDB Atlas Integration

## Tech Stack

* Node.js
* Express.js
* MongoDB & Mongoose
* EJS & EJS-Mate
* Passport.js
* Bootstrap
* Connect-Mongo
* Joi

## Installation

1. Clone the repository

```bash
git clone <your-repository-link>
```

2. Navigate to project folder

```bash
cd WanderLust
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file

```env
ATLASDB_URL=your_mongodb_atlas_url
SECRET=your_secret_key
```

5. Run the application

```bash
node app.js
```

or

```bash
nodemon app.js
```

6. Open in browser

```txt
http://localhost:8080
```
